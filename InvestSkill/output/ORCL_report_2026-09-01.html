01 标的概览与核心投资逻辑 (stock-eval)
商业模型垄断 · 估值过度折价

甲骨文公司 (Oracle Corporation, NYSE: ORCL) 创立于 1977 年，是全球企业软件、关系型数据库管理系统 (RDBMS) 和新一代云基础设施的绝对领军者。公司由拉里·埃里森 (Larry Ellison) 掌舵，凭借独创的 Oracle Database、Autonomous Database 以及完整的企业级 SaaS 应用全家桶（Fusion Cloud ERP / HCM / SCM、NetSuite），深度卡位全球财富 500 强企业的关键业务底层生命线。

在过去 3 年中，Oracle 成功实现了自创立以来最波澜壮阔的第二增长曲线跃迁——OCI (Oracle Cloud Infrastructure) Gen2 算力基建。凭借业内独一无二的高性能无阻塞 RoCE (RDMA over Converged Ethernet) 网络架构、裸金属 GPU 实例以及与微软 Azure、谷歌云 (Google Cloud)、亚马逊 AWS 达成的“破冰式”多云数据库直连协议 (Oracle Database@Azure / @Google Cloud / @AWS)，Oracle 从传统的本地软件授权巨头彻底升级为生成式 AI 大模型训练与企业推理的首选云基建提供商。

🛡️ 关键任务数据库护城河
全球前 10 大商业银行、9 大电信运营商及万余家超大型政企核心转账结算系统 100% 运行在 Oracle RAC/Exadata 上。客户替换成本极高（转换周期 3~5 年且伴随灾难性宕机风险），年度续约率常年保持在 98% 以上。
⚡ OCI Gen2 算力网络颠覆
OCI 采用平坦化网络拓扑和 RoCE 互联，在超大规模 GPU 集群训练中的网络延迟与吞吐性能较传统虚拟化网络提升 25%~30%，性价比领先 AWS 20%+，吸引了 OpenAI、xAI、Meta、Cohere 等顶尖 AI 巨头将 Oracle 作为核心算力底座。
💎 估值错杀与非对称机会
受 FY2026 单年为构建千兆瓦级 AI 数据中心而支出的 556.6 亿美元巨额 Capex 影响，市场因自由现金流短期承压而出现恐慌性抛售，股价自高点 $324.63 大幅腰斩至 $142.47（RP 13.1%），前瞻 P/E 跌破 13.0x，形成千载难逢的黄金坑。
